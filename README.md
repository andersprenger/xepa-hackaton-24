# xepa-hackaton-24
# Wiki do Alerta-Desastre
### O projeto tem como objetivo fornecer um sistema de alertas de desastres emitidos pelo governo, personalizados para a região do usuário. Além disso, o sistema oferece a opção de calcular uma rota de evacuação do endereço do usuário até o abrigo mais próximo. O projeto também permite que os usuários realizem reportes relacionados a desastres diretamente para o governo. A iniciativa visa, de maneira simples e acessível, disponibilizar essas funcionalidades para todos os tipos de usuários.

# Funcionalidades
   * Leitura de alertas de desastres.
   * Realização de reportes. 
   * Acesso a mapas de rotas de evacuação.

# User Stories
**Como um usuário:** Eu quero receber alertas de desastres específicos para a minha região, para que: eu possa tomar as medidas necessárias para minha segurança.

**Como um usuário:** Eu quero visualizar uma rota de fuga segura do meu endereço até o abrigo mais próximo, para que: eu possa evacuar rapidamente em caso de emergência.

**Como um cidadão:** Eu quero poder denunciar incidentes relacionados a desastres diretamente ao governo, para que: as autoridades possam tomar ações imediatas para resolver o problema.

**Como um usuário com diferentes níveis de experiência tecnológica:** Eu quero que o sistema seja simples e fácil de usar, para que: eu possa acessar as informações e funcionalidades sem dificuldades.
